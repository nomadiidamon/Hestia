# Hestia

System discovery, hardware and software analysis, and AI model recommendations.
Hestia provides C++ and Python implementations with shared concepts and
behavioral guarantees.

Hestia was developed by abstracting hardware and AI model recommendations from
[Domus-AI](https://github.com/nomadiidamon/Domus-AI) into a reusable tool.

## Quick Start

### C++

The C++ implementation has not yet been implemented.

### Python

```bash
cd python
pip install -e .
```
